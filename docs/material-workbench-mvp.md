# 可缝合科研素材工作台 MVP

## 产品定义

这个项目不是泛化论文推荐器，而是面向单个科研项目的可缝合素材工作台。

核心闭环：

```text
项目画像 -> 检索论文/代码线索 -> 生成素材卡 -> 按接入位置看板组织 -> 进入方案篮子 -> 生成实验路线
```

当前版本已经做到：

```text
项目画像 -> 一致性检查 -> 搜索论文 -> 相关性过滤 -> 素材卡看板
         -> Top 10 全文/代码核验 -> 深度缝合分析 -> 人工反馈 -> 方案篮子 -> 实验路线
```

## 用户目标

用户不是只想知道“哪些论文相关”，而是想知道：

- 哪些论文 idea 可以和自己的项目缝合。
- 哪些模块或架构思想能落到当前 pipeline。
- 它应该接在 backbone / neck / head / loss / data / training / experiment 哪一段。
- 接入动作是什么，难度大概如何。
- 这些素材能否进一步组合成可执行实验路线。

## MVP 决策

- 主线：项目工作台，而不是论文日报。
- 第一版对象：单研究者、单项目画像。
- 素材组织：主视图按可接入位置分栏。
- 素材卡评分：相关性、可缝合度、代码可用性三分独立，排序主分使用可缝合度。
- 缝合建议：默认规则模板；有 LLM key 时再增强生成。
- 代码理解：MVP 手动填写项目画像，后续再做轻量代码扫描。
- 数据源：MVP 从 arXiv 起步，后续扩展 Semantic Scholar 和 Papers with Code，DBLP 放到投稿评估阶段。
- 每日搜索：保留，但只是当前项目画像的新素材发现入口。

## 项目画像字段

- 项目名称
- 研究领域
- 任务类型
- 当前 idea
- 关键词
- Backbone
- Neck
- Head
- Dataset
- 每次搜索数量

## 素材卡字段

- 来源论文标题、作者、摘要、链接、PDF
- 素材类型：idea / module / architecture / code / experiment / dataset
- 可接入位置：Backbone / Neck / Head / Loss / Data / Training / Experiment
- 二级标签：例如 `Feature Fusion`、`Layer-wise Attention`、`Small-object Reweighting`
- 缝合动作建议
- 接入难度：低 / 中 / 高
- 相关性分
- 可缝合度分
- 代码可用性分
- 证据来源
- 关键证据片段
- 相关性判定与过滤原因
- 用户反馈、已读状态、方案篮子状态

## 深度缝合分析

每张素材可以进一步生成结构化分析：

- 核心问题、方法摘要、可复用模块与项目匹配点。
- 接入位置以及输入、输出、代码改动接口。
- 最小实现步骤和三段式对照实验计划。
- 预期收益、风险、原文证据、置信度和分析边界。

系统优先读取 `OPENAI_API_KEY`，使用 Responses API 的严格 JSON Schema 输出；未配置或请求失败时自动使用规则模板。分析缓存由项目画像、论文摘要、素材卡、分析引擎和 Schema 版本共同生成指纹，画像变化后自动失效。

全文核验会下载并缓存 PDF，使用 `pypdf` 提取方法、实验、消融、数据和结论段落，并记录页码；代码核验会从正文和 PDF 链接注释中识别受支持的仓库地址。深度分析只引用已提取片段，仓库“可访问”也不等于“已经成功运行”。

当前仍不解析公式、架构图和实验表格，`pypdf` 也不提供 OCR。扫描版或编码异常 PDF 会被明确标记为文本不足。

## 相关性策略

- 直接相关：同时命中遥感领域与项目当前任务。
- 可迁移：命中遥感领域和可迁移方法，或跨领域同时命中任务与方法。
- 仅供参考：只有领域证据，但缺少当前任务或方法证据。
- 不相关：缺少领域/任务组合证据，或明显属于通信、遥操作、医疗等其他方向。
- 每次搜索会用最新规则重新评估历史素材，避免旧检索噪声长期残留。

## 反馈与评估闭环

- 个性化榜单吸收“有用 / 可缝合 / 不相关”反馈，并对同接入位置、素材类型和二级标签做有限加减分。
- 固定模型 Top 10 不使用反馈加权，用于持续统计原始推荐质量，避免负反馈退出榜单后从指标中消失。
- 目标是固定 Top 10 至少 7 张正向反馈，且不相关反馈不超过 2 张。
- 默认看板展示个性化 Top 10；全部有效、有代码、低成本和接入位置筛选用于进一步复核。

## 验收标准

输入遥感 Transformer 项目画像后：

- 可以返回 20 张左右素材卡。
- Top 10 中至少 7 张让用户觉得“可能帮助落地”。
- 每张卡都有可接入位置、动作建议、三分和证据来源。
- 页面可以按接入位置看板浏览素材。
- 用户能从素材卡中挑选 3-5 张，生成规则驱动的第一轮实验路线。

## 后续迭代

1. 反馈学习：根据“有用 / 可缝合 / 不相关”反馈校准检索和排序。
2. 视觉增强：增加 OCR、方法图、公式和实验表解析，为深度分析补充多模态证据。
3. 数据源扩展：Semantic Scholar、Papers with Code、DBLP。
4. 轻量代码扫描：自动识别 backbone、neck、head、dataset、训练配置。
5. PDF 全文/架构图解析：提取方法图、公式、模块结构和实验表格。
