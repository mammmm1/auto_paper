# 循环工程迭代方式

这个项目建议按“小闭环”迭代，而不是一次性设计完整系统。

## 第 0 环：跑通

- 能新增主题。
- 能搜索 arXiv。
- 能看到摘要和推荐分。
- 能下载 Markdown/CSV。

验收标准：每天可以得到一份可读的论文列表。

## 第 1 环：摘要质量

- 引入 LLM 结构化摘要。
- 输出固定字段：研究问题、方法、核心发现、局限、适合谁读。
- 增加失败重试和缓存。

验收标准：摘要可以直接用于快速判断是否要读原文。

## 第 2 环：推荐个性化

- 增加用户反馈：收藏、跳过、已读、有帮助。
- 把反馈转成关键词权重和作者/机构偏好。
- 推荐理由变得可解释。

验收标准：推荐列表越来越接近用户兴趣。

## 第 3 环：在线化

- 增加登录和多人主题。
- 部署到云平台。
- 每天定时发送邮件、Slack 或飞书日报。

验收标准：无需打开本地机器，也能每天收到结果。
